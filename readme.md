# 마음 톡톡 · 실시간 이모티콘 보내기

초보자 수업에서 학생들이 이모티콘으로 반응을 보내고, 강사와 학생이 같은 반응을 실시간으로 확인하는 웹앱입니다.

## 파일 구성

- `index.html`: HTML, CSS, JavaScript가 들어 있는 실행 파일입니다.
- `readme.md`: 사용 방법과 제작·검사 설명입니다. 앱 실행에는 필요하지 않습니다.

## 실행 — 1단계

인터넷에 연결된 상태에서 같은 폴더의 **index.html을 더블클릭해 브라우저로 여세요.**

설치, 빌드, 로컬 서버 실행은 필요하지 않습니다. Firebase SDK를 인터넷에서 불러오므로 오프라인으로는 사용할 수 없습니다. 제작 시 Windows Chrome에서 로컬 파일 실행을 확인했습니다.

## 화면 사용 방법

| 화면 또는 버튼 | 동작 |
| --- | --- |
| 강사 모드 | 화면 안의 비밀번호 입력칸에 **1004**를 입력하면 강사 화면으로 이동합니다. |
| 학생 모드 | 비밀번호 없이 학생 화면으로 이동합니다. |
| 👍 좋아요 · ❤️ 공감해요 · 👏 응원해요 | 해당 반응을 보냅니다. 같은 버튼을 여러 번 눌러도 됩니다. |
| 처음으로 | 첫 화면으로 돌아갑니다. 강사 모드에 다시 들어갈 때는 비밀번호를 다시 입력합니다. |
| 우리 반의 실시간 반응 | 종류별 누적 횟수, 전체 횟수, 최근 반응을 보여 줍니다. |

강사 화면의 제목은 ‘우리 반 실시간 반응’, 학생 화면의 제목은 ‘지금 내 반응을 보내요!’입니다. 새 반응은 이모티콘 애니메이션으로 나타납니다. 기기의 ‘동작 줄이기’ 설정이 켜져 있으면 애니메이션을 생략합니다.

같은 Firebase 설정과 데이터 경로를 사용하는 파일은 모두 같은 반응을 공유합니다. 반별 코드나 수업별 분리 기능은 없습니다. 파일 이름을 바꾸거나 복사해도 같은 설정이면 같은 데이터에 연결됩니다.

## 연결과 전송 안내

| 화면 문구 | 의미 |
| --- | --- |
| 우리 반 연결됨 | 서버에 연결되어 초기 반응을 읽은 상태입니다. |
| 저장 확인 중 | 서버의 저장 완료 응답을 기다리고 있습니다. 아직 전송 성공이 아닙니다. |
| 서버 전송 완료 N회 | 현재 탭에서 이번에 파일을 연 뒤 서버 저장이 확인된 전송 횟수입니다. 우리 반 전체 누적과는 다릅니다. |
| 전송 실패 | 저장 요청이 실패했습니다. 화면의 한국어 안내를 확인하세요. |
| 연결 끊김 · 재연결 중 | 새 전송을 막고 재연결을 기다립니다. 화면의 집계는 마지막 수신 기준입니다. |
| — | 아직 초기 반응을 확인하지 못했습니다. 0회라는 뜻이 아닙니다. |

확인 중인 전송이 있으면 결과가 나올 때까지 탭을 열어 두세요. 시간이 오래 걸린다는 이유만으로 성공이나 실패로 판정하지 않습니다. 탭을 닫으면 미확인 전송의 저장 여부를 보장할 수 없습니다.

## 누적 횟수와 저장 방식

- 반응마다 고유 키를 만들어 기록합니다. 여러 학생이 같은 숫자를 읽고 덮어쓰는 방식으로 집계하지 않습니다.
- 서버의 저장 완료 응답을 받은 뒤에만 전송 성공을 표시합니다. 아직 확인 중인 자신의 반응은 누적 집계에서 제외합니다.
- 새로고침하거나 처음으로 돌아가도 데이터베이스에 저장된 반응은 유지됩니다.
- 최근 반응은 최대 18개, 화면에서 동시에 나타나는 애니메이션은 최대 24개입니다. 이 표시 제한 때문에 전체 누적 횟수가 줄어들지는 않습니다.
- 현재 데이터베이스에 남아 있는 유효한 반응을 집계합니다. 콘솔에서 반응 기록을 삭제하면 횟수도 줄어듭니다.
- 앱 안에는 반응 초기화 버튼이 없습니다.

## Firebase 설정

사용자가 제공한 설정은 이미 `index.html`의 `firebaseConfig`에 들어 있습니다. 별도의 키 입력창이나 로그인 화면은 없습니다.

| 항목 | 현재 파일의 설정 |
| --- | --- |
| 서비스 | Firebase Realtime Database |
| 프로젝트 ID | `test1-6601c` |
| 데이터베이스 주소 | `https://test1-6601c-default-rtdb.asia-southeast1.firebasedatabase.app` |
| 반응 경로 | `practice/reactions` |
| SDK | Firebase 12.18.0 compat, CDN 스크립트 태그 2개 |
| 로그인·회원가입 | 사용하지 않음 |
| 별도 AI API | 사용하지 않음 |

제공된 databaseURL의 마크다운 링크 표기는 실제 HTTPS 주소만 추출했습니다. API 키의 이스케이프된 밑줄은 실제 밑줄로 반영했습니다. 다른 프로젝트 주소를 임의로 만들지 않았습니다.

## 비밀번호와 데이터 보안

**1004는 실습용 화면 진입 제한이며 실제 데이터 보안을 보장하지 않습니다.** 비밀번호 확인 코드는 HTML 안에 들어 있습니다. 데이터 접근 권한은 Firebase 보안 규칙으로 결정됩니다.

이 앱은 사용자가 콘솔에서 읽기·쓰기를 허용한 실습 환경을 전제로 합니다. 앱이 보안 규칙을 설정하거나 변경하지는 않습니다. 테스트 모드 규칙의 실제 내용과 만료일은 콘솔에서 확인이 필요합니다.

## 문제가 있을 때 먼저 확인할 것

증상에 해당하는 첫 확인만 안내합니다. 추가 설정이 필요하면 해당 화면의 문구를 알려 주세요.

| 증상 | 첫 확인 |
| --- | --- |
| Firebase 도구를 불러오지 못했다고 나옴 | 인터넷에 연결되어 있는지 확인하세요. |
| 반응 읽기 실패 또는 접근을 허용하지 않았다고 나옴 | 강사가 Firebase 콘솔에서 현재 데이터베이스 보안 규칙을 확인해야 합니다. |
| 설정값 또는 databaseURL이 없다고 나옴 | `index.html`의 `firebaseConfig`에 제공된 설정이 들어 있는지 확인하세요. 주소를 임의로 만들지 마세요. |
| 전송 버튼을 누를 수 없음 | 화면 상단의 연결 상태를 확인하세요. |
| 저장 확인 중이 계속 표시됨 | 탭을 열어 둔 상태에서 인터넷 연결을 확인하세요. |
| 다른 수업의 반응도 함께 보임 | 두 파일이 같은 Firebase 프로젝트와 `practice/reactions` 경로를 사용하는지 확인하세요. |
